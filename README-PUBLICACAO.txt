GREEN DEALS BR — LANDING PAGE V1

Arquivos:
- index.html: página principal
- styles.css: identidade visual e responsividade
- script.js: ano automático no rodapé
- privacy.html: política de privacidade
- terms.html: termos de uso
- affiliates.html: aviso de afiliados
- assets/: logo e favicon

Publicação gratuita sugerida:
1. Crie uma conta gratuita no GitHub, se ainda não tiver.
2. Crie um repositório público chamado greendealsbr-site.
3. Envie todos os arquivos desta pasta para a raiz do repositório.
4. Abra Settings > Pages.
5. Em Source, escolha Deploy from a branch.
6. Selecione main e /root; salve.
7. O GitHub fornecerá um endereço temporário.
8. Em Settings > Pages > Custom domain, informe greendealsbr.com.br.
9. No Registro.br, configure os registros DNS indicados pelo GitHub Pages.
10. Ative Enforce HTTPS quando a opção aparecer.

Antes de cadastrar nos afiliados:
- Teste o site no celular e no computador.
- Abra links e páginas legais em janela anônima.
- Confirme Instagram, Telegram e WhatsApp.
- Não publique alegações como “menor preço histórico” sem dados verificáveis.
